第三国际的伟大贡献

从国际工人联合，到反帝、反法西斯的共同斗争。

← 返回文献馆 · 阅读季米特洛夫的两篇作品 →

第三国际，又称共产国际，于1919年在莫斯科成立。它把第一次世界大战后各国革命者的联系组织起来，为传播马克思主义、建设共产党、协调跨国行动提供了共同的平台。其重要贡献，可以沿着以下五条线索阅读。〔成立决定〕

一、把国际主义化为组织与协作

共产国际通过代表大会、文件交流和各国党之间的联络，使国际工人运动能够共同讨论战略、组织建设和劳动者的处境。1919年的成立决定以建立新的国际组织为实际任务；此后各次大会文件保留了这些讨论的轨迹。这种协作让“全世界无产者，联合起来”成为持续的组织工作和共同议程。〔历次大会与文件〕

二、支持殖民地、半殖民地人民的解放

第三国际把殖民地和被压迫民族的问题纳入世界革命的议程，号召把工人运动同反帝、民族解放斗争联系起来。1920年东方各民族代表大会的宣言，集中表达了反对殖民压迫、争取劳动人民解放的诉求。它的重要意义，在于推动欧洲工人运动与亚洲等地区被压迫人民建立政治上的联系。这里所述为大会宣言的政治方向，具体国家的实践仍须结合当地史料考察。〔东方各民族代表大会宣言〕

三、帮助中国早期共产主义组织建立国际联系

在中国共产党筹建时期，共产国际代表与中国早期共产党组织建立了联系。1921年，马林和尼克尔斯基参加了中共一大；大会通过的第一个纲领提出联合第三国际。这是第三国际支持中国革命的一项具体历史贡献。中国共产党的创立同时植根于中国先进分子的探索、工人运动的发展和各地早期组织的工作。〔1921年大事记〕 〔中共一大史料说明〕

四、推动反法西斯统一战线

1935年共产国际第七次代表大会上，季米特洛夫系统论述工人阶级联合反对法西斯主义的任务，主张把共产党人、社会民主党人以及更广泛的劳动群众联合起来。他特别强调，工人阶级的团结还会影响农民、城市小资产阶级和知识分子，为反法西斯人民阵线提供了重要的理论与策略说明。〔本馆报告节选与原文〕

五、组织声援，支援西班牙人民的反法西斯斗争

西班牙内战期间，共产国际围绕支援西班牙共和国开展国际协作。1937年6月8日，季米特洛夫向第二国际主席发电报，建议建立联合行动的联络机制，并表示愿意讨论其他可行形式。这封电报具体展示了国际主义如何落实为协调组织、交换建议、共同援助的工作。〔电报全文〕 〔西班牙战争相关文件〕

历史时间轴

  1. 1919年3月：第三国际成立，建立新的国际共产主义组织。
  2. 1920年9月：东方各民族代表大会发表宣言，把反帝与民族解放问题推向共同议程。
  3. 1921年7月：共产国际代表参加中国共产党第一次全国代表大会。
  4. 1935年7—8月：第七次代表大会讨论反法西斯统一战线；季米特洛夫8月2日作主要报告。
  5. 1937年6月：季米特洛夫就联合援助西班牙提出具体建议。
  6. 1943年5—6月：执委会主席团提出解散建议；6月声明宣布解散安排，以6月10日为生效时间。〔5月决议〕 〔6月声明〕
