# 国际共运图志

独立的静态历史地图与文献阅读项目。由 QmlmReader 国际共运栏目迁移，原项目不再作为运行或构建依赖。

- 世界地图：24个历史截面、212个国家／地区参考面，57条国家／政权沿革、44个历史节点和12条组织资料。
- 完整栏目：世界图志、历史日历、深度专栏、时事档案、纪念与第三国际介绍。
- 八部关联文献，3819段正文；章节目录、正文搜索、段落链接、阅读设置、专注、收藏、历史、笔记及TXT／笔记Markdown导出。
- 全部运行资源位于仓库内，不需要账号或在线地图密钥。组织资料分别标明证据日期，不作为实时名册。

## 本地运行

安装 Node.js 22或更新版本，无需安装 npm 依赖：

```sh
npm start
```

打开 http://127.0.0.1:4174/ 。预览也支持 `/international-communist-atlas/` 项目前缀。

```sh
npm run build
npm test
```

发布目录为 `dist/`。构建只读取本仓库；重新生成地图衍生资源、八个文献页面和搜索索引。源码档案、迁移脚本、测试缓存不会发布到网页。构建不执行目录清理或批量删除。

## 地图使用

鼠标滚轮缩放，拖动平移；地图聚焦后可用方向键及加减键操作。手机默认允许页面滚动，启用“触屏拖动”后可平移地图。缩放范围80%—600%。

先选择社会主义国家，再放大至180%以上，显示本国或各加盟共和国的首都。群岛附图可用Tab、Enter或空格选择中国。“查看中国及南海诸岛”同时取景大陆、台湾和南海岛屿。

**中国在1949年及以后截面固定显示红色**，包括中性地理模式；1949年以前按原阶段资料显示。该项是展示规则，历史记录和编辑路线判断不随颜色改写。大陆、台湾、西沙、南沙等同属中国区域。南海海域不填成陆地。

地理数据来自自然资源部标准地图服务系统公开的原生平面数据，保留已定界、未定界、海岸线及南海诸岛归属范围线的区别。现代参考几何不等于历史国境复原，原有标准图审图号不用于本专题。印度武装资料只表示受影响县所在邦的参考外框，不能当作组织控制区。

## 搜索与保存

顶部“搜索”或Ctrl／⌘+K打开全站搜索。结果最多20条，包含文献章节与命中片段；文献使用 `?paragraph=段落ID&q=关键词` 定位。失效目标显示提示，不悄悄跳到其他段落。搜索资料首次使用时加载，失败可重试并保留已有结果。

本项目本地存储键：`icm-atlas:preferences:v1`、`icm-atlas:cursor:v1`、`icm-atlas:reader:v1`。与原站的键分别保存。笔记仅在当前浏览器中保存；浏览器禁用存储时提示“未持久保存”，本次会话仍可导出。点击正文或用Tab选中段落后记笔记；输入均按纯文本显示。

## 发布

GitHub Actions在main分支更新时执行构建与静态检查，然后发布 `dist/` 到GitHub Pages。目标公开地址：

https://madongchen57-ops.github.io/international-communist-atlas/

需要在仓库设置中将Pages来源设为GitHub Actions。首次发布由维护者完成GitHub CLI浏览器授权；仓库不保存令牌或账户凭据。
